# Buck Cockrell Portfolio Homepage

This package contains the first working homepage for the portfolio.

## Upload to GitHub

1. Download and unzip the package.
2. In the `buck-portfolio` repository, upload:
   - `index.html`
   - `styles.css`
   - `script.js`
3. Replace the existing `index.html` when GitHub asks.
4. Commit directly to `main`.
5. Netlify should redeploy automatically.

## Important

The homepage links to individual story folders that do not exist yet, so clicking a story will return a 404 until those pages are added.

The cards for Stories 3–9 are working editorial drafts derived from the available career materials. We should compare them with the finalized story document before treating the wording as final.
